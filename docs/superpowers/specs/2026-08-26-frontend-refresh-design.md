# Фронтенд: структура и обновление вида

## Задача

Две работы, которые делаются вместе, потому что вторая невозможна без первой.

`server/app.ts` разросся до 1848 строк — половина кода приложения в одном
файле. Тринадцать функций-страниц вперемешку с двумя десятками помощников.

Вид приложения вызывает три конкретные претензии: слишком плотно, палитра и
шрифты выглядят старомодно, неудобно на телефоне.

Подача остаётся редакционной, а не продуктовой. Но засечки уходят: заказчик
просит «менее печатный» вид. Literata меняется на **Ysabeau** — свободный
шрифт с Google Fonts, гротеск с гарамоновской основой. Он держит характер,
не выглядя книжной вёрсткой. Тёмную тему не делаем: не просили.

Отдельная цель, названная прямо: **сайт не должен выглядеть сделанным ИИ.**
Признаки, по которым это считывается, и что с ними делаем, — в разделе 4.

## 1. Разбивка кода

```
server/
  app.ts          — только маршрутизация: URL → страница (~120 строк)
  pages/          — feed, tender, entity, entities, officer, officers,
                    supplier, suppliers, railway, article, updates,
                    prices, lookup
  components/     — case-row, filters, risk, verdict, directory
```

Граница реза: **вместе меняется — вместе лежит.** Не «все типы в types.ts» —
это разносит связанное и заставляет прыгать между файлами при каждой правке.

Два модуля напрашиваются сами. `directoryPage`, `readDirControls`,
`applyDirControls` и `dirBar` уже делятся между тремя страницами-справочниками.
`presetsFor`, `presetBar`, `sortBar`, `filterPanel`, `groupBlock` работают и
меняются вместе.

**Переезд строго механический** — вырезать и вставить, ни одной правки по
пути. Визуальные изменения идут отдельными коммитами после. Иначе случайное
изменение поведения растворится в перестановке двух тысяч строк.

Проверка: 244 теста остаются зелёными **без единой правки в самих тестах**.
Пришлось поменять тест — значит, переезд не был механическим.

## 2. Визуальная система

Сейчас четыре оттенка поверхности, неразличимые глазом, и холодный
голубоватый отлив во всей палитре — это и читается как «госсайт середины
десятых». Разворачиваем в тёплый нейтральный.

```css
/* ритм — всё кратно 4px, других значений в стилях не остаётся */
--s1:.25rem  --s2:.5rem   --s3:.75rem  --s4:1rem
--s5:1.5rem  --s6:2rem    --s7:3rem    --s8:4rem

/* бумага и чернила */
--paper:#FCFCFA        /* фон страницы, тёплый */
--surface:#FFFFFF      /* карточки */
--surface-2:#F3F3EF    /* колодцы: фильтры, врезки */
--ink:#14181A
--ink-soft:#565B60
--ink-faint:#8B9096
--line:#E4E3DD

--accent:#0F5C8C  --accent-bg:#E8F0F7

--alarm:#B02418  --warn:#8A6100  --calm:#1E6B43

--radius:8px  --radius-sm:4px

/* шрифты: Ysabeau вместо Literata, один суперсемейный набор */
--f-display:"Ysabeau","Segoe UI",system-ui,sans-serif
--f-body:"Ysabeau","Segoe UI",system-ui,sans-serif
--f-mono:"IBM Plex Mono",Consolas,monospace
```

**Шкала важнее величин.** Воздух даёт не увеличение отступов, а сокращение их
числа с двадцати случайных до восьми. Заголовок отстоит от текста на `--s2`,
блок от блока — на `--s7`. Глаз ловит ритм.

**Радиус 5px → 8px.** Пять ничему не кратно и выглядит случайным.

**Тень одна.** Двухслойная с размытием 24px — приём эпохи материального
дизайна. Карточкам хватает рамки; тень остаётся у выдвижной панели, которая
действительно висит над содержимым.

**Ysabeau вместо Literata.** Шрифт уже подключается с Google Fonts — правится
строка `<link>` в `layout()` и переменная. Ysabeau идёт и в заголовки, и в
текст: это гротеск, рассчитанный и на крупный кегль, и на основной набор.
Две гарнитуры вместо трёх — меньше шума и один опознаваемый голос вместо
безопасной пары. IBM Plex Mono остаётся на кодах и номерах.

Числовые показатели переводим на `--f-body` с `tabular-nums`: они были
набраны заголовочной гарнитурой, отсюда рябь в строке статистики.

## 3. Телефон

Сейчас три брейкпоинта (64rem, 44rem, 22rem) и правки «по месту». Меняем
подход: базовые стили — мобильные, брейкпоинты только добавляют, а не
переопределяют.

**Панель фильтров.** На узком экране пресеты, сортировка, группировка и
«Більше фільтрів» выстраиваются в четыре ряда контролов над списком —
пользователь до данных не доходит. Сворачиваем в одну кнопку «Фільтри», по
нажатию — та же выдвижная панель, что уже используется для навигации.
Выбранные фильтры показываем счётчиком на кнопке, чтобы состояние не пряталось.

**Строка списка.** Складывается в блок с ясной иерархией: сумма первой —
именно по ней сканируют, — затем замовник, потім ознаки. Сейчас порядок
обратный, и на узком экране сумма теряется.

**Касания.** Все интерактивные цели не меньше 44px по меньшей стороне.
Звёздочка «зберегти» сейчас заметно меньше.

**Широкие таблицы** на страницах цін и статей получают свой
`overflow-x:auto`, чтобы страница не ехала горизонтально целиком.

## 4. Логотип и «не как ИИ»

Заказчик даёт готовый знак — радар с роботом, бирюзово-синий, на почти чёрном
квадрате. Ставим **как есть**, это его решение, принятое с открытыми глазами:
я показал, во что знак превращается в размере фавикона (32px), и что робот со
свечением — сам по себе маркер «сгенерировано ИИ».

Ассеты нарезаны из исходника в `public/`: `favicon-32.png`, `icon-180.png`
(iOS), `icon-192.png`, `icon-512.png`, `logo-source.png` (квадрат 768).
В шапке знак идёт скруглённой плиткой — у него собственная тёмная подложка,
и без скругления на светлой шапке это читается как чёрный прямоугольник.

Что ещё выдаёт «сделано ИИ», помимо картинки, и что с этим делаем:

- **Всё одинаково скруглено и в карточках.** Убираем часть коробок, разделяем
  блоки линиями и воздухом — приём редакционной вёрстки, а не дашборда.
- **Идеально ровная сетка одинаковых плиток.** Даём заголовку и первой
  колонке больше веса: асимметрия читается как решение, симметрия — как шаблон.
- **Безопасная пара «серифный заголовок + гротеск текст».** Уходит вместе с
  Literata: один Ysabeau во всех ролях.

## Проверка

- 244 существующих теста зелёные, без правок в тестах.
- `npm run typecheck` чистый.
- Каждая из тринадцати страниц открывается и отрисовывается на 375px и 1440px.
- Ни одного значения отступа вне шкалы `--s1`…`--s8` в `html.ts`.

## Чего не делаем

- Тёмную тему.
- Превращение списка в таблицу — это продуктовая подача, а не редакционная.
- Перерисовку логотипа: ставим тот знак, который дал заказчик.
- Никаких новых зависимостей: у проекта их ноль, и это остаётся так.
