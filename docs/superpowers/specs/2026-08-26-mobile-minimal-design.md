# Мобильная лента: радикальный минимализм

## Задача

Главный сценарий на телефоне — **листать свежее, «что нового»**. Всё
подчиняем этому: строка должна читаться на бегу, лишнее — прочь.

Сейчас на узком экране до первого тендера нужно проскроллить шесть блоков
служебного текста: заголовок, подзаголовок, строку счётчиков, полоску
«1-2-3», блок «Як читати», кнопку фільтрів и строку «показано N». Это и есть
«перегружен».

Всё, что делаем, живёт в `@media (max-width:44rem)` — десктоп не меняется.
Никакого JavaScript: сайт серверный, и это остаётся так.

## 1. Убрать всё лишнее над лентой

На узком экране первый экран показывает тендеры, а не объяснения.

- **Подзаголовок** `.sub` («Публічні закупівлі всієї України…») — скрыть.
- **Полоску `.primer`** (1-2-3) и блок `details.help` («Як читати цю
  сторінку») — скрыть; онбординг доступен ссылкой на `/about`, которая в
  ленте уже есть.
- **Строку `.statline`** (36 773 · 789 млрд · …) — демотировать в одну тихую
  мелкую строку у счётчика результата, не отдельным крупным блоком.
- **Заголовок `h1`** остаётся, но кегль меньше.

Итог: заголовок + кнопка «Фільтри» + первый тендер в первом экране.

Всё это — `display:none` или уменьшение внутри медиазапроса. На десктопе
блоки остаются как есть.

## 2. Строка тендера: один взгляд

Перестраиваем `.row` внутри медиазапроса по приоритету сканирования:

```
● 28,79 млрд ₴                    ☆
Укргідроенерго
Київська область · вер. 2022
3 ознаки · ціну змінили після торгів
```

- **Сумма — якорь:** крупно (`1.05rem`, уже задано в задаче 6), первой,
  `tabular-nums`.
- **Цветная точка остроты** слева от суммы: `rowSeverity()` уже возвращает
  `proven|high|medium|clear|low`. Точка `::before` или маленький `span`,
  цвет из токена (`--alarm`/`--warn`/`--calm`/`--ink-faint`). Заменяет
  отдельную красную метку «Понад мільярд» в ленте.
- **Замовник** — одна строка, `text-overflow:ellipsis`.
- **Регион · дата** — мелко и тихо (`--ink-faint`), дата в формате «мес. рік».
- **Ознаки — ОДНА строка** вместо 1–3 предложений: количество + самая
  важная коротко. Формат: `<N> ознак · <shortRisk верхней ознаки>`.
  `shortRisk()` и `rankRisks()` уже есть в `components/risk.ts`. Полный
  список — на карточке тендера по тапу.
- **Номер `UA-...`** — убрать из строки ленты; он остаётся на странице
  тендера.
- **Звёздочка** — верхний правый угол, цель касания 44px (задача 6).

Вся строка кликабельна и ведёт на тендер (ссылка уже оборачивает строку).

Это меняет РАЗМЕТКУ строки, значит правится `components/case-row.ts`, не
только стили. Замеряем в `tests/render.test.ts`: маркер `/` (h1) остаётся,
но проверить, что строки по-прежнему содержат сумму и ведут на тендер.

## 3. Фильтры: всё за одной кнопкой

Оставляем единый триггер «Фільтри» со счётчиком активных (задача 6). Ничего
не выносим наружу — «свернуть по максимуму». Один тап открывает панель;
панель уже переиспользует `.drawer`. Здесь менять нечего, кроме проверки,
что после части 1 триггер по-прежнему на месте и первый ряд под ним.

## Проверка

- 244 существующих теста зелёные; правки в тестах только если меняется то,
  что тест утверждает про строку (сумма, ссылка на тендер).
- `npm run typecheck` чистый — сверяется контроллером по сырому выводу.
- На 375px: заголовок, кнопка «Фільтри» и первая строка тендера видны без
  прокрутки; в строке нет номера `UA-...`; ознаки — одна строка; точка
  остроты окрашена по severity.
- На 1440px десктоп не изменился: подзаголовок, полоска 1-2-3, счётчики и
  полная строка на месте.
- `document.documentElement.scrollWidth <= clientWidth` на 375px = true.

## Чего не делаем

- Не меняем сортировку по умолчанию — она общая с десктопом; «Найновіші»
  доступна пресетом. Отдельная правка, если понадобится.
- Не трогаем десктоп.
- Не добавляем JavaScript.
- Не выносим пресеты видимой лентой чипов — заказчик просил свернуть по
  максимуму; всё за одним триггером.
- Не убираем ознаки из ленты совсем — одна строка остаётся сигналом.
